# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-09-24

### Added

* Initial public release.
* Local MySQL-based task list.
* Todoist API integration.
* Todoist Today task support.
* Today tasks displayed before other Todoist tasks.
* Today task highlighting.
* Todoist task completion.
* Todoist task editing.
* Todoist task deletion.
* Local task editing.
* Local task deletion.
* Task movement from Todoist to Todolist.
* Task movement from Todolist to Todoist.
* Automatic Today assignment when moving local tasks to Todoist.
* Predefined B (Business), P (Personal) and W (Work) task labels.
* Label editing for Todoist and local tasks.
* Label preservation when moving tasks between Todoist and Todolist.
* Preservation of unrelated Todoist labels when editing managed labels.
* Local task ordering by creation date.
* Compact table-based task interface.
* Mobile-friendly layout.
* Confirmation dialogs for task actions.
* User authentication.
* Password change support.
* Per-user Todoist API key storage and configuration.
* CSRF protection.
* Flash message support.
* MySQLi database access.
* Apache URL rewriting.
* Subdirectory installation support.
* VC Framework integration.
* No Composer dependency.
* PHP 5.3+ compatibility.
